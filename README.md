# Portfolio

Personal portfolio built with React, Vite and React Router.

## Run locally

```bash
npm install
npm run dev
```

## Structure

- `src/components` — header, logo, theme toggle, footer
- `src/pages` — About, Projects, Experience, Research & Achievements, Resume
- `src/data` — site details, navigation and project entries
- `src/index.css` — light/dark theme tokens and all styles
- `public/images` — project meta images; `public/resume.pdf` — resume file
